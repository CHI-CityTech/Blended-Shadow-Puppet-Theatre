# Automation

Automation covers mechanisms, actuators, software, and integration that make puppets or scenic elements move. Keep season-specific implementation here, separated by the system being automated.

- `puppetry/`: puppet actuation and control
- `set/`: control and actuation for scenic mechanisms

The physical mechanism and its operating/safety documentation remain with Set. Shared QLab conventions and reusable scripts remain under `control/qlab/`.
